# Reconciliation of remaining Leatherworking item effects

Updated: **2026-11-09**. Forgebook contains **512** item-tooltip entries.

The source comparison reports from the older Forever Talent tooltip and newer Bind on Forever tooltip originally showed a mixture of mechanical differences, omitted details, extra annotations, and unresolved spell-template placeholders. They are **not the same as 16 live gameplay errors**.

The current machine-readable reconciliation is [docs/effect-reconciliation-report.json](effect-reconciliation-report.json), regenerated by `scripts/build-effect-reconciliation-report.py`.

## Actual corrections applied

### All six Mystic/Forceful kits

The original import showed implausible raw spell-table substitutions like `75 Spell Power / 0 Armor` or `0 Attack Power / 0 Armor`. Newer client-derived Forever Mastery recipes, ForeverDB client values and spell effect detail corroborate:

| Kit | Bonus applied to target gear | Minimum target item level |
|---|---|---|
| Mystic Heavy | **+4 Spell Power, +24 Armor** | 15 |
| Forceful Heavy | **+6 Attack Power, +24 Armor** | 15 |
| Mystic Thick | **+5 Spell Power, +32 Armor** | 25 |
| Forceful Thick | **+8 Attack Power, +32 Armor** | 25 |
| Mystic Rugged | **+6 Spell Power, +40 Armor** | 35 |
| Forceful Rugged | **+10 Attack Power, +40 Armor** | 35 |

Source: https://forevermastery.com/en/items/252452-mystic-heavy-armor-kit and corresponding individual item pages; ForeverDB item records. Their **item quality, character level and minimum Leatherworking craft skill are separate fields** from the target equipment item-level minimum.

### Additional effect text fixes

- **Light/Medium Armor Kits** and **Heavy Leather Ball**: restored a recorded one-second use cooldown. Bonuses unchanged.
- **Tanning Rack**, **Sewing Machine**, **Camp Tent**: restored the shared one-hour camping cooldown and campfire requirement. Rack and Machine can replace a tent. Verified against Forever's current camping wiki pages.
- **Green Whelp Armor**: omitted a duplicate `(Proc chance: 5%)` suffix. The 5% effect remains.
- **Red Whelp Gloves**: show the sourced `5% chance of dealing 30–50 Fire damage` instead of appending contradictory `(Proc chance: 10%)` metadata. A visible warning notes the 5%/10% issue; only in-game proc evidence could determine whether the separate percentage refers to the same mechanic.
- **Invulnerable Mail**: different spelling / duplicated "sec" on an external site; kept the existing canonical 5% proc and 10-second internal cooldown, confirmed by independent Forever tooltip pages.

## What still requires in-game verification

4. Core Armor Kit — `+3 Defense / target level 45+` versus Wowhead's `+4 / 0+`.

These five keep their displayed values and warning text in `data/item-stats.json`; source-backed corrections are reapplied from `data/item-stats-corrections.json` by `scripts/build-item-stats.py`.
